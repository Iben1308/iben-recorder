# Iben Recorder

Автономний аудіореєстратор для Android 8.1+ (спочатку створений для Samsung Galaxy J7 2016
з LineageOS). Тривалий фоновий запис із поділом на файли, вбудований програвач і
необов'язкове завантаження на ваш власний WebDAV-сервер (наприклад, Nextcloud).

🇬🇧 [English version](README.md)

> **Статус:** особистий проєкт, версія 0.7.x. Розробляється й використовується однією
> людиною, тому можливі недоліки. Перш ніж покладатися на застосунок, перевірте
> багатоденний запис на своєму телефоні.

## Можливості

- **Запис:** безперервне захоплення з мікрофона, AAC у M4A, моно, налаштовувані бітрейт і
  частота дискретизації, налаштовувана тривалість файлів, фоновий сервіс із постійним
  сповіщенням (воно видиме весь час запису).
- **Керування локальним сховищем:** ліміт архіву, резерв вільного місця, необов'язкове
  автовидалення найстаріших власних файлів.
- **Вкладка «Слухати»:** програвач із хвилею (масштаб 1×/4×/16×), закладки з нотатками,
  позначки «прослухано» та «важливо», груповий вибір і групові дії, експорт.
- **Завантаження WebDAV:** HTTPS на ваш сервер; пароль зберігається в Android Keystore;
  передачу перевіряють порівнянням SHA-256; переспрямування відхиляються; звичайний HTTP
  дозволено лише для приватних адрес локальної мережі після явного підтвердження;
  самопідписаний сертифікат можна імпортувати й довіряти йому лише для цього підключення.
- **Безпечне видалення з хмари:** файл видаляється з сервера лише після перевірки розміру
  через `HEAD` та умовного `DELETE` із `If-Match`.
- **Інтерфейс:** три вкладки (Слухати / Запис / Налаштування), світла й темна теми,
  українська, англійська та польська мови.
- **Приватність:** без Google Play Services, Firebase, реклами, аналітики та сторонніх
  бібліотек. Єдиний мережевий трафік іде на WebDAV-сервер, який ви налаштуєте.

## Вимоги

- Android 8.1 (API 27) або новіший (`targetSdk 35`)
- WebDAV-сервер, якщо потрібне хмарне завантаження (необов'язково)

## Збірка

Потрібні: JDK 17, Python 3.11+, Android SDK (версії платформи й build-tools — у
`app/build.gradle`), інтернет під час першої збірки.

```bash
bash tools/check.sh   # перевірки логіки
bash build.sh         # завантажує Gradle 8.9 і збирає debug APK
```

Debug APK буде в `app/build/outputs/apk/debug/app-debug.apk`. Для релізів підписуйте
власним ключем і зберігайте його: для кожного наступного оновлення потрібен той самий ключ.

## Відповідальне використання

Запис інших людей може вимагати їхньої згоди та регулюється законами багатьох країн.
Ви самостійно відповідаєте за законне використання застосунку. Під час запису він
показує постійне сповіщення й не призначений для прихованого запису.
